**10. UI 设计与接入**

| 模块 | 文件 | 功能 |
|------|------|------|
| 头部 | `src/ui/shared/header.js` | 项目标题渲染 |
| Tab切换 | `src/ui/shared/tabSwitch.js` | 基础/进阶模式切换，切换时清空游戏状态 |
| 基础面板 | `src/ui/basic/panel.js` | 序列长度+最大回合数表单，校验+提交 |
| 进阶面板 | `src/ui/advanced/panel.js` | 有效物品数+总物品数+最大回合数表单，校验+提交 |
| 游戏页面 | `src/ui/shared/gamePage.js` | 槽位渲染、物品池、反馈、历史列表、回合计数 |
| 结算弹窗 | `src/ui/shared/modal.js` | 通关/失败弹窗，历史记录展示，再来一局/返回设置 |
| 主入口 | `src/main.js` | 状态管理，事件总线（sm:submit-basic/advanced/guess/reset/retry） |
| 主HTML | `index.html` | 容器结构，Tailwind 编译后样式 |
| Tailwind | `tailwind.config.js` | 本地预编译，content 指向 index.html 和 src/ui/**/*.js |

**交互逻辑：**
- 点击物品 → 空位1时直接放入，空位>1时进入待放置状态 → 点击目标槽位放置
- 槽位有物品时点击 → 物品移回物品池（需无待放置物品）
- 提交猜测 → 空槽位用 `❓` 填充 → 与 answer 比对 → 更新反馈/历史/回合计数
- 有限回合模式显示「已尝试 X 次 | 剩余 X 次提交」

**弹窗按钮：**
- 「再来一局」→ `sm:retry-game` → 同参数重开新局
- 「返回设置」→ `sm:reset-game` → 返回对应模式的参数面板

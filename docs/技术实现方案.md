# $Sequence Master$ -技术实现方案

## 1. 技术栈选型（轻量高效）

- 基础架构：HTML5 + TailwindCSS + 原生JavaScript
- 运行方式：纯前端本地运行，无服务端、无数据库依赖
- 部署形态：单页H5，可直接浏览器运行，可打包桌面端/小程序

## 2. 核心模块拆分

### 2.1 参数配置模块

接收用户输入：序列长度、总物品数、回合上限；内置参数校验逻辑：进阶模式下总物品数 ≥ 有效物品数，禁止非法数值，参数异常弹窗提示。

### 2.2 谜底随机生成模块

基础模式：从物品池随机抽取对应数量不重复物品，生成谜底序列。进阶模式：生成有效谜底序列，再补充随机干扰项，合并为全局物品池。

### 2.3 核心比对算法模块（核心）

1. 优先遍历比对，统计「完全正确（位置+物品）」数量；
2. 剔除完全匹配项后，剩余物品做交集统计，得出「物品对位置错」数量；
3. 去重防误判，严格遵循密码机计分规则。

### 2.4 对局状态模块

管理剩余回合、当前轮次、对局锁定状态；每轮提交后冻结操作，计算结果后解锁；判断胜利/失败条件，触发结算页面。

### 2.5 历史记录模块

数组存储每一轮：猜测序列、正确数、位置错误数，实时渲染页面历史列表。

### 2.6 UI交互模块

支持点击/拖拽排布物品、参数切换、模式切换、动画反馈、结算弹窗。

## 3. 关键逻辑规则

- 所有谜题默认无重复物品，预留开关可扩展重复模式
- 不限回合模式：回合数值置空，不做次数校验
- 通关条件：本轮完全正确数量 = 序列总长度
- 失败条件：有限回合下，回合数用尽未通关

## 4. 开发交付标准

- 逻辑零BUG：计分、判定、随机生成无异常
- 适配PC/移动端基础尺寸
- 界面简洁干净，无冗余元素，适合录屏
- 代码注释清晰，模块化拆分，方便后续迭代

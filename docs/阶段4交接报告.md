## 发布流程 SOP（下次发版照抄）

1. 改代码 → 本地验证 → `npm run build` 通过
2. 同步版本号：`package.json` + `src-tauri/tauri.conf.json`（如 1.0.1）
3. 并行出包：先 `TAURI_ENV_PLATFORM=windows npm run build` 预生成 Tauri 模式 dist，
   再同时跑 `npx tauri build --config '{"build":{"beforeBuildCommand":"echo skip-dist"}}'`（Win）
   与 `ANDROID_HOME=E:/Android/Sdk JAVA_HOME=E:/Java/jdk-17.0.20.1+1 NDK_HOME=E:/Android/Sdk/ndk/27.2.12479018 npx tauri android build --apk --config 同上`（安卓）
4. 校验：apksigner verify + 产物时间戳，全绿再上传
5. commit（内联身份 `-c user.name=... -c user.email=...`）→ `git push origin main` + `git push gitee main`
6. 打 tag：`git tag v1.0.1` → 双端推 tag（GitHub CI 自动构建 Windows 资产）
7. 手动上传：GitHub Release 补 APK（改名 `SequenceMaster_<ver>_universal.apk`）；Gitee 发行版传三资产
8. 两端 Release 正文按双语模板更新，保持一致

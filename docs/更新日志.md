# 更新日志

本文件记录 **Sequence Master（序列大师）** 的所有重要变更。
版本号遵循语义化版本规范；core 层模块 API 在历次版本间保持向后兼容，无破坏性变更。

## [1.0.0] - 2026-10-04

首个正式发布，一套代码三端交付（网页 / Windows / 安卓）。

### 新增
- 安卓端（Tauri 2）：已签名 universal APK，覆盖 4 种 CPU 架构，最低支持 Android 7.0（minSdk 24），离线可玩
- 安卓原生状态栏安全区适配（edge-to-edge + WindowInsets 顶部留白）
- 响应式页头：小屏（<640px 逻辑像素）自动切换紧凑小字号，大屏维持原尺寸
- 下载落地页安卓卡片接入真实链接：Gitee 国内高速为主、GitHub 原站备用

### 变更
- Windows 端窗口锁定为固定 1000×720，禁止缩放与最大化
- 桌面/移动客户端内隐藏"下载"入口（仅网页端显示）
- 安卓启动图标改用应用母图重新生成

## [0.5.0] - 2026-10-03

### 新增
- Gitee 镜像仓库作为国内高速下载通道；下载页 Windows 卡片改为 Gitee 主 + GitHub 备

### 变更
- 下载页主图标 1024px → 192px（300KB → 66KB），慢网首屏加载提速

## [0.4.0] - 2026-10-03

### 新增
- Windows 桌面端（Tauri 2）：MSI 安装包 + NSIS 安装向导，GitHub Actions 按 `v*` 标签自动构建发布
- 由单一母图生成三端图标（Windows / 安卓 / 网页 favicon）

### 修复
- Tauri 客户端白屏：Vite `base` 按目标自动切换（Tauri 用 `./`，GitHub Pages 用 `/Sequence-Master/`）

## [0.3.0] - 2026-10-03

### 新增
- Vite 多页构建（`index.html` + `download.html`），Tailwind 经 PostCSS 自动编译进产物
- GitHub Pages 部署工作流上线，公开站点可访问
- 独立下载落地页（占位阶段）与 favicon

## [0.2.0] - 2026-10-03

### 新增
- 完整可玩 UI：模式 Tab 切换、基础/进阶参数面板、猜测槽位与物品池交互、每回合反馈、历史记录、结算弹窗
- UI 与 core 层通过事件总线解耦；Tailwind 样式本地预编译

### 说明
- 需本地 HTTP 服务器运行（ES Module 在 `file://` 下受 CORS 限制）

## [0.1.0] - 2026-10-02

### 新增
- 进阶模式核心：`validateAdvancedConfig`、`generateAdvancedAnswer`（一次 Fisher-Yates 同时切出有效物品与干扰项）
- 双维度反馈（位置对 / 物品对错位）在进阶场景下完成验证；通关/判负判定直接复用基础模式状态机，零改动

### 说明
- 对阶段 1 模块零修改，纯增量扩展

## [0.0.0] - 2026-10-01

### 新增
- 项目骨架：零依赖 HTML5 + 原生 ES Module，哨兵常量统一收敛在 `appMeta.js`
- core 引擎七模块：参数校验（`validate`）、物品池（`itemPool`，12 项冻结 emoji）、谜底生成（`answerGen`，Fisher-Yates 无重复）、比对算法（`compare`，先剔全对再消耗式交集）、对局状态（`gameState`，非法提交不吃回合）、历史记录（`history`，双层冻结）
- 每个 core 模块配套命令行 debug 验证入口，期望值内置、自动 [OK]/[FAIL] 比对

# Sequence Master 上传与三端发布规划

## 一、目标

将已完成的游戏内核与 UI 发布为三端产品，共用同一份 `src/` 源码：

- 网页版：GitHub Pages 托管，浏览器直接可玩
- Windows 版：`.exe` / `.msi` 安装包，本地运行
- Android 版：`.apk` 安装包，移动端运行

三端互为补充：网页版负责传播与试玩，桌面与移动版负责离线游玩与体验完整度。网页版页头常驻"下载"入口，引导用户获取本地安装包。

## 二、技术选型

- 构建工具：**Vite**。三端共用一份 `dist/` 产物，源码只改 `src/`
- 桌面 + 移动：**Tauri 2.0**。一套 `src-tauri/` 配置同时产出 Windows 与 Android
- 网页托管：**GitHub Pages**，地址 `https://jason-frog.github.io/Sequence-Master/`
- 下载分发：**GitHub Releases**，网页版"下载"按钮指向最新 Release
- 版本管理：从 `1.0.0` 起，`package.json` 与 `tauri.conf.json` 同步

## 三、目录结构

```txt
Sequence-Master/
├── src/                  # 源码，三端共用
│   ├── core/             # 游戏内核（已冻结）
│   └── ui/               # 界面
├── debug/                # 命令行验证脚本
├── src-tauri/            # Tauri 配置（阶段 4.2 起）
├── dist/                 # 构建产物（gitignore，CI 生成）
├── index.html
├── package.json
├── vite.config.js
└── tailwind.config.js
```

## 四、上传策略

先上传「阶段 1-3 的能跑基线」，再引入构建工具与三端打包。

- **基线价值**：当前源码已全部人工验收通过，是已知可工作的 checkpoint。先推送它，后续每次引入新工具（Vite、Tauri、Android SDK）都有前一个可用版本可回退。
- **不做合并提交**：上传基线与引入 Vite 必须是两个独立 commit，方便 `git diff` 定位与 `git revert` 回退。
- **忽略规则先行**：`.gitignore` 必须覆盖 `node_modules/`、`dist/`、`src-tauri/target/`，避免大文件污染仓库。

## 五、阶段划分

### 阶段 4.1：网页版上线

- 引入 Vite，产出 `dist/`
- 部署 `dist/` 到 GitHub Pages
- 页头加"下载"入口，第一阶段显示"即将上线"占位
- 保留 `node debug/debug-*.mjs` 直接可跑的能力
- Tailwind 编译并入构建流程

### 阶段 4.2：Windows 桌面版

- `tauri init` 初始化 `src-tauri/`
- 配置 `tauri.conf.json`，复用 `dist/` 产物
- 打包 `.exe` / `.msi`，发第一个 GitHub Release
- 网页版"下载"按钮接上真实链接

### 阶段 4.3：Android 版

- 搭建 Android 工具链：Android Studio + JDK 17+ + SDK / NDK
- 同一 Tauri 项目出 `.apk`
- 发布到 GitHub Releases

## 六、约束

- Vite `base` 写死 `'/Sequence-Master/'`（Pages 带子路径，错则白屏）
- 不动 `src/core/*` 任何文件
- 不动 `package.json` 的 `"type": "module"`
- 只做网页版时不碰 Tauri、不碰 Android
- UI 触摸友好性在阶段 4.3 前复核一次

## 七、验收标准

- 阶段 4.1 完成：`https://jason-frog.github.io/Sequence-Master/` 能打开完整游戏，页头有下载占位按钮，Console 无 error
- 阶段 4.2 完成：Windows Release 可下载、可安装、可离线游玩
- 阶段 4.3 完成：Android Release 可下载、可安装、触屏交互正常
- 全流程：网页版、桌面版、移动版三者版本号一致

## 八、风险与挂账

- Tauri 2.0 的 Android 支持较新，阶段 4.3 可能需备选方案（Capacitor）
- 中文用户名 `杰森青蛙` 已通过英文别名 `Jason-Frog` 规避 URL 编码问题
- 三端版本同步依赖发版流程；若后续体量增长，引入 GitHub Actions 自动化构建与部署
